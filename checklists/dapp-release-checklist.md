# DApp Release Checklist

## Application

* [ ] Critical user journeys passing
* [ ] Supported browsers validated
* [ ] Error states validated
* [ ] Loading and pending states validated
* [ ] Production configuration verified

## Wallet

* [ ] Wallet connection works
* [ ] Wallet disconnection works
* [ ] Account switching works
* [ ] Network switching works
* [ ] Rejected signatures handled
* [ ] Rejected transactions handled

## Blockchain

* [ ] Correct chain configured
* [ ] Correct contract addresses configured
* [ ] Transaction submission validated
* [ ] Transaction confirmation validated
* [ ] Contract state validated

## Services

* [ ] API smoke tests passing
* [ ] RPC connectivity verified
* [ ] Indexer operating normally
* [ ] Indexed state reconciles with blockchain
* [ ] Monitoring operational

## Release

* [ ] Known issues reviewed
* [ ] Residual risk documented
* [ ] Rollback/recovery approach understood
* [ ] Release approval obtained
